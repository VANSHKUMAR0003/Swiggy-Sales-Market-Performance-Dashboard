# 📊 Swiggy Sales & Market Performance Dashboard

## 📝 Short Description

This project presents an interactive *Swiggy Sales & Market Performance Dashboard*, built using Microsoft Excel to analyze overall sales performance, customer ratings, food preferences, restaurant performance, and geographical sales distribution.

The dashboard provides meaningful insights into key business metrics such as total sales, average rating, average order value, rating count, total orders, monthly sales trends, daily and weekly sales performance, food category distribution, and state-wise sales. Interactive slicers and visualizations enable users to explore the data and support data-driven business decision-making.

---

## 🛠️ Tech Stack

📊 *Microsoft Excel* – Dashboard development, data visualization & business reporting

🔄 *Power Query* – Data cleaning and transformation
